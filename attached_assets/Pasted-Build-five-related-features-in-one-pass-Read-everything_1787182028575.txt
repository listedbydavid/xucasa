The Core Rules (apply to everything below)

Rule 1 — Agent contact display:

Represented buyer (assignedAgentUserId is set) viewing any listing → always shows their assigned agent's contact info
Unrepresented buyer (assignedAgentUserId is null or set to '55534280') viewing any listing → shows the listing agent's contact info
Guest (not authenticated) viewing any listing → shows the listing agent's contact info
If no listing agent info exists → show David Hussain (id: '55534280') as platform agent

Rule 2 — Unrepresented buyer lead assignment:

Every unrepresented buyer who creates an account, swipes, saves, or views a listing is silently assigned to David Hussain (assignedAgentUserId = '55534280') in the background if not already assigned
David's info does NOT show on listing cards — listing agent still shows there
David shows as their agent everywhere else: dashboard "Your Agent" card, profile, notifications
If buyer later manually links their own agent via POST /api/buyer/link-agent → their agent replaces David and they exit David's lead pool
Log all silent assignments as assignmentType: 'platform_default' in audit trail
This applies at: account creation, first swipe, first save, first property view (authenticated)

Rule 3 — Representation is protected:

A represented buyer's agent is never replaced by a listing agent, a share link, or any automated logic
Only the buyer themselves can change their agent via the Find Agent flow

Feature 2 — Silent platform default agent assignment
Create a shared helper (server/lib/assignPlatformAgent.ts)
typescript
import { DAVID_USER_ID } from './agentAssignment'; // already exists

/**
 * Silently assigns David Hussain as platform default agent
 * to any user who has no assigned agent yet.
 * Call this on: account creation, first swipe, first save, first authenticated property view.
 * No-op if user already has an assigned agent.
 */
export async function assignPlatformAgentIfNeeded(
  userId: string,
  storage: IStorage,
  audit: typeof executeWithAudit
): Promise<void> {
  const user = await storage.getUser(userId);
  if (!user || user.assignedAgentUserId) return; // already assigned, skip

  await storage.updateUser(userId, { assignedAgentUserId: DAVID_USER_ID });

  await audit({
    eventType: 'platform_agent_assigned',
    actorUserId: userId,
    actorRole: user.primaryIntent ?? 'buyer',
    outcome: 'success',
    metadata: {
      assignmentType: 'platform_default',
      agentId: DAVID_USER_ID,
      trigger: 'auto',
    },
  }, async () => ({ data: null }));
}
Wire this helper into these 4 trigger points:
Account creation — in server/replit_integrations/auth/replitAuth.ts or wherever new users are created, call assignPlatformAgentIfNeeded after the user record is created
First swipe — in POST /api/buyer-interest and POST /api/swipe-interest, call it before creating the buyer_interest row (already partially done via resolveBuyerAgent — verify it covers this)
First save — in POST /api/saved-properties, call assignPlatformAgentIfNeeded for the authenticated user
First property view — in GET /api/properties/:id/contact-agent, call it for authenticated users with no agent (already in the endpoint logic above)
