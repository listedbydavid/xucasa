Build the agent-first listing workflow. This is the core go-to-market feature — agents create listings and share them with clients who don't have accounts yet. Read everything before starting.

The Core Flow
Verified agent creates a listing (off-market, coming soon, or their active MLS listing)
Agent gets a shareable link they copy and send via text, email, DM — however they want
Anyone who taps the link sees the listing with the agent's info front and center
Guest can view everything — photos, details, price, agent contact
Guest wants to save or message → prompted to create a free account
When they create an account → automatically linked to the agent whose link they tapped

// Update the Zod schema for POST /api/properties to accept:
const createListingSchema = z.object({
  // Status
  status: z.enum(['active', 'coming_soon', 'pre_market', 'off_market', 'pending', 'sold']).default('active'),

  // Basic info
  title: z.string().min(1).max(200),
  description: z.string().max(2000).optional(),
  price: z.number().int().positive(),
  propertyType: z.enum(['Single Family', 'Condo', 'Townhouse', 'Multi-Family', 'Land', 'Mobile', 'Commercial']).optional(),

  // Address
  addressStreetNumber: z.string().optional(),
  addressStreetName: z.string().min(1),
  addressUnitNumber: z.string().optional(),
  addressCity: z.string().min(1),
  addressState: z.string().default('CA'),
  addressZip: z.string().optional(),

  // Property details
  beds: z.number().int().min(0).optional(),
  baths: z.number().min(0).optional(),
  sqft: z.number().int().min(0).optional(),
  lotSize: z.number().int().min(0).optional(),
  hoaFee: z.number().int().min(0).optional(),
  yearBuilt: z.number().int().min(1800).max(2030).optional(),

  // Listing details
  listDate: z.string().optional(), // ISO date string
  openHouseDate: z.string().optional(),
  openHouseTime: z.string().optional(),

  // Agent-only fields
  showingInstructions: z.string().max(500).optional(),
  confidentialRemarks: z.string().max(500).optional(),
  lockboxType: z.string().optional(),
  accessInstructions: z.string().max(500).optional(),

  // Coming soon / pre-market
  expectedListDate: z.string().optional(), // when it will hit MLS
  preMarketNotes: z.string().max(500).optional(), // agent notes for pre-market

  // Source
  source: z.enum(['manual', 'coming_soon', 'off_market']).default('manual'),
});

After creating the property, set agentId = req.user.claims.sub so the listing is attributed to the creating agent.

Photo upload endpoint
typescript
POST /api/properties/:id/photos
isAuthenticated + must be property owner (agentId === caller)
Content-Type: multipart/form-data
Field: photos (multiple files, max 20, each max 10MB)
Accepted: image/jpeg, image/png, image/webp, image/heic

Handler:
1. Verify caller owns this property
2. For each uploaded file:
   - Use sharp to resize to max 2400px wide, convert to webp, quality 85
   - Save to dist/public/listing-photos/{propertyId}/photo-{timestamp}-{index}.webp
   - URL: /listing-photos/{propertyId}/photo-{timestamp}-{index}.webp
3. Update property.photos array by appending new URLs
4. Return { photos: string[], total: number }

Also add:
DELETE /api/properties/:id/photos
Body: { photoUrl: string }
Removes one photo URL from the array
Caller must own the property
