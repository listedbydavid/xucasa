Check for these categories:
1. UI components with no backend:
bashgrep -rn "fetch\|apiRequest\|useQuery" client/src/components/ client/src/pages/ --include="*.tsx" | grep -v "node_modules"
For each API call in the frontend, confirm the corresponding endpoint exists in server/routes/. Flag any that call endpoints that don't exist.
2. Backend endpoints with no frontend:

3. Schema tables with no routes:
sqlSELECT table_name FROM information_schema.tables
WHERE table_schema = 'public'
ORDER BY table_name;
For each table, confirm there is at least one API route that reads or writes to it. Flag orphaned tables.
