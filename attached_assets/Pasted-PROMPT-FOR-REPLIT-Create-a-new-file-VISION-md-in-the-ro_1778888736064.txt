markdown# Xucasa — Vision, Mission & North Star

## Who We Are

Xucasa is a real estate platform built by an agent, for agents — while also being
genuinely better for buyers and homeowners. We are not a lead generation tool.
We do not sell user data to the highest bidder. We do not disintermediate agents
or undercut the relationships they have built with their clients.

We are the alternative.

---

## Who We Serve

### Buyers
- Transparent, swipe-first home discovery
- Seller terms and concessions visible upfront — no surprises at the table
- No data sold, no lead routing to strangers
- A guided path to representation without pressure

### Homeowners
- Know everything about your home — value, equity, flood risk, zoning, permits
- Tools to sell on your terms, not the portal's terms
- Direct access to verified local vendors for repairs, maintenance, and improvements
- Historical inspection data for full transparency

### Agents
- A platform that keeps your clients yours
- Beacon: prove buyer demand before a listing goes live
- Confidential MLS fields, showing instructions, and private remarks — agent eyes only
- CRM, buyer interest tracking, and client collaboration tools built in
- No dependency on Zillow, Redfin, or Trulia — your listings, your relationships

### Lenders
- A trusted partner channel to pre-approved, actively searching buyers
- Transparent integration — no hidden referral fees or data selling

### Vendors
- A verified local directory for home services
- Buyers and homeowners connect with trusted pros for bids and repairs
- Pest, plumbing, HVAC, landscaping, gutters, renovation, garage doors, and more

---

## The Three Questions

Every feature, every product decision, every API integration must pass this test:

1. **Does this increase transparency for buyers?**
2. **Does this give homeowners more power over their own data and decisions?**
3. **Does this make agents more effective without creating a new dependency?**

If the answer to all three is yes — build it.
If it compromises any of them — don't.

## For Developers and AI Assistants

If you are reading this before making changes to xucasa:

1. Read this document fully before writing a line of code
2. Run the test suite before and after your changes (`npx tsx server/__tests__/*.test.ts`)
3. Check TypeScript: `npx tsc --noEmit` — target is 0 errors
4. Every mutation needs audit logging via `executeWithAudit`
5. No direct buyer ↔ listing agent messaging — all communication is agent-mediated
6. No storing or exposing user data beyond what is necessary for the feature
7. When in doubt, ask: does this serve the buyer, the homeowner, and the agent
   without compromising any of them?

The north star is a platform where every party in a real estate transaction
feels represented, informed, and respected.
