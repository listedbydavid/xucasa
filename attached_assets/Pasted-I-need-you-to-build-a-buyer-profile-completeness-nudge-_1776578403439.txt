I need you to build a buyer profile completeness nudge. The goal is to prompt buyers to fill in mustHaves, homeTypes, and preferredCities — the fields that are currently empty on almost every profile and that directly power Beacon matching and future recommendations.

Context
The buyer_profiles table has these fields that are almost universally empty:

must_haves — text array, e.g. ["pool", "garage", "single story"]
nice_to_haves — text array
deal_breakers — text array
home_types — text array, e.g. ["Single Family", "Condo"]
preferred_cities — text array, e.g. ["San Diego", "La Jolla"]
move_in_timeline — text, e.g. "1-3 months"
min_beds, max_beds, min_baths, min_sqft, max_sqft — integers

We need buyers to fill these in because they power Beacon (agents use them to prove demand before listing) and will power future recommendations.

Part 1 — Profile completeness score (server-side)
In server/storage.ts, add a pure function buyerProfileCompleteness(profile: BuyerProfile): { score: number; missingFields: string[] } that returns:

score: 0–100 based on which fields are filled
missingFields: human-readable list of what's missing

Use these weights:
FieldPointsLabel if missingminBeds or maxBeds15"Bedroom preferences"minBaths10"Bathroom minimum"preferredCities (non-empty array)20"Preferred cities"homeTypes (non-empty array)15"Home type preferences"mustHaves (non-empty array)20"Must-have features"moveInTimeline10"Move-in timeline"minSqft or maxSqft10"Size preferences"
Export this function so it can be used in both the API route and unit tests.

Part 2 — API endpoint
In server/routes.ts, add:
GET /api/buyer-profile/completeness — requires auth

Finds the caller's active buyer profile
Returns { score, missingFields, profile } using buyerProfileCompleteness()
If no profile exists yet: returns { score: 0, missingFields: [], profile: null, noProfile: true }

PATCH /api/buyer-profile — requires auth

Allows buyers to update their profile fields
Accepts: minBeds, maxBeds, minBaths, minSqft, maxSqft, preferredCities, homeTypes, mustHaves, niceToHaves, dealBreakers, moveInTimeline
Validates with Zod — all fields optional
Normalize moveInTimeline: replace en-dash (–) with hyphen (-) and lowercase before saving
Audit log with executeWithAudit
Returns updated profile + new completeness score

Create client/src/components/BuyerProfileNudge.tsx:
