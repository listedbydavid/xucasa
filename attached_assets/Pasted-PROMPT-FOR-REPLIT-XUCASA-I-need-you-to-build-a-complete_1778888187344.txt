Overview
Two layers of in-product guidance:

Page-level guided tours — multi-step spotlight walkthroughs with a tooltip card, Back/Skip/Next buttons, progress indicator. Auto-trigger on first visit per user per page. Global skip flag: skip once = skip everywhere forever.
Contextual tooltips — PageTip (inline dismissible hints) and HelpTooltip (hover/tap explanations). Per-tip dismissal persisted per user.
"What's New" changelog modal — shown to users when new features ship.
Restart button — corner help bubble that lets users restart tours or view changelog.
Admin editor — /admin/tours page where admins can edit tour step content, reorder steps, add/remove steps, and preview tours.

Tooltip card: Positioned adjacent to the target element based on placement. Uses xucasa's shadcn/ui Card component. Contains:

Step title (16px, font-weight 500)
Step body (14px, muted foreground)
Progress: "Step X of Y" + thin amber progress bar (bg-amber-500)
Buttons: Back (ghost), Skip (ghost, text-muted), Next/Finish (amber: bg-amber-500 hover:bg-amber-600 text-white)

Mobile behavior: On viewports < 768px, render the tooltip as a bottom sheet (fixed bottom-0, full width, rounded-t-xl, bg-background) instead of a floating card. The spotlight still shows behind it.
Data flow:
