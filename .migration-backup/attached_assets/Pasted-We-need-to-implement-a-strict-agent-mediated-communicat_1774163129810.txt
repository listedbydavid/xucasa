We need to implement a strict agent-mediated communication architecture across xucasa using Option B.

CRITICAL BUSINESS RULE:
Buyers and homeowners/sellers must NEVER communicate directly with one another inside the platform.
Buyers must also NEVER communicate directly with the listing agent.
All communication must flow through licensed agents.

We are choosing Option B:

1. buyer ↔ assigned agent
2. assigned agent ↔ listing agent

The buyer must never see or access the assigned-agent-to-listing-agent conversation.
The listing agent must never have a direct conversation with the buyer.
The seller/homeowner must not have direct messaging access to buyers.

Build this as a platform-level rule enforced in schema, API validation, and UI.
