# Retired migration reference

This directory is a source-code reference from before the pnpm workspace
migration, not an application or deployment target. Do not install or run its
legacy package manifest. Its obsolete npm lockfile has been retired.

Use the root `pnpm-workspace.yaml`, `pnpm-lock.yaml`, and the packages under
`artifacts/` and `lib/` for installation, development, and deployment.
Historical dependency resolutions remain available in Git history.
